# PixelSprite AI 👾

Instant 2D Game Sprites & Retro Pixel Asset Generator powered by **Pollinations AI**.

[![Made with pollinations.ai](https://raw.githubusercontent.com/pollinations/pollinations/main/packages/ui/src/brand/badge-made-with.svg)](https://pollinations.ai/?ref=badge)

## 🌟 Overview
**PixelSprite AI** is a lightweight, responsive web tool designed for indie game developers, Telegram Mini App creators, and digital artists. It generates high-resolution, retro-styled 2D game characters, consumables, weapons, and tilesets in real time using Pollinations AI's turbo image generation models.

## 🚀 Features
- **Instant AI Pixel Generation:** Rapid text-to-sprite inference powered by `tongyi-mai/z-image-turbo` and Pollinations API.
- **Game Engine Ready:** Multiple aspect ratios (1:1 square, 4:3 cards, landscape) and style presets (8-bit NES, 16-bit Arcade, 32-bit Isometric, GBA).
- **Direct Download & Export:** Instant download as PNG for PixiJS, Phaser, Godot, or Unity.
- **Zero Install:** Pure standalone frontend (HTML5 + Tailwind CSS + Vanilla JS).

## 🛠️ Tech Stack
